# Version Control Practice

## Project Description
This repository is created as part of the **Version Control Assignment** to demonstrate proficiency in using Git and GitHub. The project serves as a practical exercise in initializing repositories, managing commits, and navigating the Git workflow

## Version Control Practice
This section was added via a feature branch [cite: 50, 51] to practice collaborative development workflows:
**Branching**: Creating isolated environments for specific updates.
**Pull Requests**: Simulating the review process before merging changes.
**Merging**: Integrating verified changes back into the main branch.
**Synchronization**: Pulling updated code from the remote repository to the local machine.
